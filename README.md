# Resume — Flávio Freitas

Currículo e portfólio profissional com foco em desenvolvimento de software, aplicações web, inteligência artificial e produtos digitais.

## Estrutura

- `index.html` — conteúdo da página inicial
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação mobile e animações de entrada
- `assets/` — imagens e outros recursos; a foto profissional pode ser adicionada como `assets/profile.jpg`

## Publicação no GitHub Pages

No GitHub, acesse **Settings → Pages** e, em **Build and deployment**, selecione:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`

Após a publicação, o endereço padrão deverá seguir o formato:

`https://zoqvera.github.io/Resume-Flavio-Freitas/`

## Próximos ajustes recomendados

1. Inserir foto profissional.
2. Substituir os placeholders de e-mail e LinkedIn.
3. Adicionar links reais para projetos e repositórios.
4. Refinar a seção de tecnologias conforme o nível de domínio de cada ferramenta.
